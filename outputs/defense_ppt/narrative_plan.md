# 基于 ESP32 智能眼镜的视觉导航与语音交互系统 - 答辩 PPT 叙事计划

## 答辩主线

这套系统面向视障/低视力人群的出行辅助场景，核心问题是：如何用低成本可穿戴硬件，在有限算力和网络条件下完成实时视觉感知、语音交互和导航提示。

PPT 采用“背景意义 -> 需求目标 -> 系统架构 -> 关键实现 -> 测试验证 -> 创新总结”的答辩结构，重点突出三个工程亮点：

1. ESP32 智能眼镜负责采集摄像头、麦克风和设备端扬声器播放，通过 UDP 与服务器保持低延迟连接。
2. Go 后端承担 HTTP/WebSocket/UDP 编排，将设备流、前端控制、Python 视觉 worker 和 DashScope 实时 AI 串联起来。
3. Python worker 集成盲道分割、障碍物检测、斑马线/红绿灯检测、寻物与语音命令处理，形成可切换的导航状态机。

## 页面安排

1. 封面：项目名称、汇报人/指导教师/专业班级占位符，突出“视觉导航 + 语音交互 + ESP32 智能眼镜”。
2. 研究背景与意义：视障出行中的实时感知、过街判断和自然交互痛点。
3. 需求分析与设计目标：实时、低成本、可扩展、可调试、可部署。
4. 系统总体架构：ESP32 设备、Go 后端、Python worker、AI 服务、Vue 控制台的数据流。
5. 硬件与通信方案：摄像头/麦克风/扬声器、UDP 音视频上传、HTTP/WS 控制和可视化。
6. 软件模块划分：固件、后端、视觉 worker、前端、部署文档/资产。
7. 导盲路径算法：图像方向校正、YOLO 分割、偏移估计、障碍物辅助检测、语音提示。
8. 过街与红绿灯流程：盲道模式进入过街，斑马线对齐，红绿灯状态判断，完成后回到导盲。
9. 语音交互与 AI：ASR 命令识别、Qwen Omni 多模态问答、设备端和浏览器端音频分流。
10. 前端控制台与调试：实时画面、模式切换、导航事件、质量指标和日志。
11. 测试与验证：Python 语法编译、Go 单元测试、前端构建、接口验收。
12. 难点与创新点：低延迟流媒体、跨语言协同、导航状态机、多模型融合、可部署性。
13. 总结与展望：已完成能力与后续优化方向。
14. Q&A：答辩收束页。
