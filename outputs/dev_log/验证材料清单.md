### 2. 演示视频（待补 ⏳，最高优先级）

> 位置建议：`outputs/verification/video/作品演示视频.mp4`

- [ ] 时长 3–5 分钟，MP4（H.264，1080p 或 720p）
- [ ] 内容至少覆盖：
  - [ ] 设备实物展示（ESP32 眼镜外观、佩戴效果）
  - [ ] 系统启动 → 前端控制台画面
  - [ ] 语音交互（ASR 命令识别、千问问答）
  - [ ] 盲道导航模式（视觉分割 + 语音提示）
  - [ ] 过街 / 红绿灯检测流程
  - [ ] 高德语音导航播报（含盲道覆盖率等）
  - [ ] 避障 / 两轮车检测提示
- [ ] 有字幕或旁白说明关键操作
- [ ] 拍摄时展示真实硬件与真实场景，非纯屏幕录制
